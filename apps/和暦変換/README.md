# 和暦変換

和暦の年を入れると、**西暦**と、**同じ年をほかの元号でいうとどうなるか**（明治まで）を出します。

> 例：**令和2年** ＝ 西暦2020年 ＝ 平成32年 ＝ 昭和95年 ＝ 大正109年 ＝ 明治153年

「有効期限 平成32年3月まで」のような、改元前に書かれた書類を読むときや、
昭和何年生まれかを西暦から逆算したいときに使ってください。

---

## 使い方

**`和暦変換.html` をダブルクリックして開くだけです。** これ1つで動きます。

- インストール不要・インターネット接続も不要
- 元号を選んで年の数字を入れると、**その場ですぐ**結果が出ます（ボタンを押す必要はありません）
- 入れた内容はご自分のパソコンの中だけで処理され、外部には一切送信されません

| ボタン | はたらき |
|---|---|
| 今年 | 今年（令和◯年）を入れます |
| 消す | 入力を空にします |

## 出るもの

| | |
|---|---|
| 西暦 | 大きく表示します |
| ほかの元号でいうと | 新しい元号から順に並びます。入力した年には印が付きます |
| 改元の年の注記 | その西暦が改元をまたぐ年のとき、変わり目の日付を出します |
| 干支 | 十干十二支と読みかた（例：庚子／かのえ ね） |
| 年齢 | その年に生まれた人の、今年の満年齢 |

## ご注意：実際には使われなかった年も出ます

**「平成32年」は、実際には存在しない年です。** 平成は31年（2019年4月30日）で終わっています。

このツールは「もしその元号がそのまま続いていたら何年にあたるか」を計算して出しています。
書類に書く正式な年としては使えません。**改元をまたぐ計算のための、読み替え用**とお考えください。

## 改元の日

| 元号 | はじまり | おわり |
|---|---|---|
| 明治 | 1868年1月25日※ | 1912年7月30日（明治45年） |
| 大正 | 1912年7月30日 | 1926年12月25日（大正15年） |
| 昭和 | 1926年12月25日 | 1989年1月7日（昭和64年） |
| 平成 | 1989年1月8日 | 2019年4月30日（平成31年） |
| 令和 | 2019年5月1日 | — |

※明治への改元そのものは1868年10月23日ですが、その年の1月1日までさかのぼって明治元年とされました。

**このツールは「年」だけで計算します。** 上のとおり改元は年の途中で起きるので、
改元の年（1912・1926・1989・2019年）については、月日によって元号が変わります。
その年を入れたときは画面に注記が出ますので、あわせてご確認ください。

## 開発者向け

`和暦変換.html` の1ファイルだけです。ビルドはありません。直接編集してください。

元号を足すときは、ファイル内の `ERAS` に1行足すだけで、選択肢も換算表も自動で増えます。

```js
{ name:"令和", offset:2018, last:null }   // 西暦 = offset + 和暦の年
```

改元の年の注記は `KAIGEN`（西暦の年で引く表）に足します。

古い庁内パソコンでも動くよう、JavaScriptは ES5（`var` と `function` だけ）で書いています。
外部から読み込むファイルはありません。
