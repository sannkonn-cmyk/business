# 業務ツール置き場

日々の仕事のこまごました手間を減らすための、小さなツールを1つずつ置いています。
どれも **HTMLファイル1つで動きます**。インストールもインターネット接続も不要です。

## ツール一覧

| ツール | できること |
|---|---|
| [公用文ジェネレーター](apps/公用文ジェネレーター/) | 通知文の体裁を整えた **Wordファイル** を書き出す。文書番号・あて先・発信者などを画面で入力するだけ |
| [和暦変換](apps/和暦変換/) | 和暦の年を入れると **西暦** と、それ以前の元号での換算年（例：令和2年＝平成32年＝昭和95年）を表示 |

## 使い方

各フォルダの中にある **HTMLファイルをダブルクリック** するだけです。

- 入力した内容はすべて自分のパソコンの中だけで処理され、外部のサーバーには送信されません
- 社内サイトや GitHub Pages などに置いて、URLで開いてもかまいません

くわしい説明は、各フォルダの `README.md` をご覧ください。
