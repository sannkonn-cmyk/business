# 原典資料の置き場所

このフォルダに原典資料を置いてください。ここに置いたものから
`chiiki/data/*.json` を機械的に作ります。**JSON を手で書くことはありません。**

原典は出典を示すためリポジトリに含めます（`.gitignore` しません）。

---

## 置いていただきたいファイル

### 必須

| # | 資料 | 置くファイル名 | 入手先 |
|---|---|---|---|
| 1 | 大字・町丁目レベル 位置参照情報　**最新年度版** | `isj_32_最新.csv` | 国土交通省 位置参照情報ダウンロードサービス |
| 2 | 同　**平成15年度版**（合併前） | `isj_32_旧.csv` | 同上 |
| 3 | 過疎地域市町村等一覧 | `過疎地域市町村等一覧.pdf` | 総務省 過疎対策 |
| 4 | 特別交付税措置に係る地域要件確認表 | `地域要件確認表.pdf` | 総務省 |

**1 と 2 について。** zip を展開すると `32_2023.csv` のような名前の Shift_JIS の CSV が出てきます。
名前を変えて置いてください。中身の文字コードは Shift_JIS のままで構いません（UTF-8 でも読めます）。

**2 の年度について。** 島根県の平成の大合併（雲南市・安来市 平成16年、松江市・出雲市 平成17年、
斐川町の出雲市編入 平成23年）は、**平成15年度版1つですべて合併前**にあたります。
他県に広げるときは、その県の合併時期より前の年度版が要ります。

**3 について。** 全部過疎／一部過疎（みなし過疎を含む）の別と、
一部過疎の市町村については**条件不利区域にあたる旧市町村名**が載っているものをお願いします。

### あると (c) の判定ができるようになるもの

| # | 資料 | 置くファイル名 | 所管 |
|---|---|---|---|
| 5 | 振興山村 指定地域一覧 | `振興山村一覧.pdf` | 農林水産省 |
| 6 | 離島振興対策実施地域 一覧 | `離島振興対策実施地域一覧.pdf` | 国土交通省 |
| 7 | 半島振興対策実施地域 一覧 | `半島振興対策実施地域一覧.pdf` | 国土交通省 |

仕様書 §8 で「入手方法が未確認」とされていた3つです。

**揃わなくても実装は進みます。** 揃った法令だけを `照合済み法令` に立て、
残りの法令に該当しうる市町村では、区域(c) を「対象」と言い切らずに「要確認」に落とします。
（条件不利区域(b) は4法令の和集合なので、(b) は1つ載っていれば言えますが、
(c) は「どれにも載っていない」ことなので全部の一覧が要る、という非対称のためです。）

揃った時点でファイルを足して取り込み直せば、プログラムを触らずに (c) が出るようになります。

### 形式について

PDF・Excel・CSV のいずれでも構いません。PDF はこちらで読み取ります。
ただし PDF の表は読み取りで崩れることがあるため、**いったん中間CSVに落として
目で確かめられる形にしてから** JSON にします（下記「中間CSV」）。

## 取り込みの流れ

```
[原典]  isj_32_最新.csv ── 位置参照情報（現在の大字＋代表点）
        isj_32_旧.csv   ── 位置参照情報（合併前の大字＋代表点＋旧市町村コード）
        各種一覧          ── 法令別の区域リスト

  ↓ ① node chiiki/tools/ingest/match-oaza.js
        新旧の代表点を突き合わせ、現在の大字に旧市町村名を当てる
        → 中間CSV  chiiki/data/source/中間_大字と旧市町村.csv

  ↓ ② 一覧から中間CSVを作る（PDFはこちらで読み取ります）
        → 中間CSV  chiiki/data/source/中間_区域指定.csv
        → 中間CSV  chiiki/data/source/中間_市町村区分.csv

  ↓ ③ node chiiki/tools/ingest/build-data.js
        → chiiki/data/d1_municipalities.json
        → chiiki/data/d2_oaza.json

  ↓ ④ node chiiki/tools/check-data.js   整合性の検査
     node chiiki/tools/ingest/report-coverage.js   収録率・要確認率
     node chiiki/tools/build.js         配布物を書き出す
```

## 中間CSV の形

取り込みの途中を人が読める形で止めるためのものです。
①はツールが作りますが、手で直しても構いません（直したら③から流し直してください）。

**`中間_大字と旧市町村.csv`**（①が生成）

```
大字町丁目コード,市町村コード,市町村名,大字名,旧市町村コード,旧市町村名,突合方法,突合距離m,要確認理由
32201001001,32201,松江市,殿町,32201,松江市,同名一致,0,
```

**`中間_市町村区分.csv`**（②で作る）

```
市町村コード,市町村名,区分,指定都市区分,該当法令,三大都市圏,人口減少率例外
32201,松江市,一部条件不利地域,該当なし,過疎|山村,0,0
```

- `区分` … `都市地域` / `全部条件不利地域` / `一部条件不利地域`
- `指定都市区分` … `該当なし` / `条件不利地域を含まない` / `条件不利地域を含む`
- `該当法令` … `過疎|山村|離島|半島|奄美|小笠原|沖縄` を `|` 区切り
- `三大都市圏` `人口減少率例外` … 1 か 0

**`中間_区域指定.csv`**（②で作る）

```
市町村コード,旧市町村名,法令,出典,基準日
32201,旧八雲村,過疎,過疎地域市町村等一覧,令和4年4月1日
```

条件不利区域(b) にあたる旧市町村を、法令ごとに1行ずつ並べます。
ここに出てこない旧市町村は (c) として扱われます。
そのため、**この表に載せた法令は `照合済み法令` に立ち、載せていない法令は立ちません。**

**`取得記録.json`**

いつ・どこから落としたかと、**どの法令の区域一覧を投入したか**を残します。
`資料` は根拠テキストの出典欄に出ます。

```json
{
  "基準日": "令和4年4月1日",
  "収録法令": ["過疎"],
  "資料": [
    { "名称": "過疎地域市町村等一覧", "url": "https://...", "現在日": "令和4年4月1日", "取得日": "2026-08-23" }
  ]
}
```

`収録法令` がこの仕組みの要です。ここに書いた法令だけが各市町村の `照合済み法令` に立ち、
書いていない法令に該当しうる市町村では、区域(c) が「対象」ではなく「要確認」になります。
**一覧を投入していないのに `収録法令` に書くと、確かめていないことを確かめたことにしてしまいます。**
実際に投入した法令だけを書いてください。

## 取り込みが正しく動くかは、原典なしでも確かめられます

```
node chiiki/tools/test-ingest.js     # 新旧の突合（合併で大字名が変わる場合など）
node chiiki/tools/test-pipeline.js   # 原典CSV → 中間CSV → JSON → 判定 の通し
```

合成データで動かすので、原典が届く前でも流せます。
実データで思ったとおりに動かないときは、まずこの2つを流して、
取り込みの仕組み自体が壊れていないかを確かめてください。
